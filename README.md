# Netflix Data Analysis Dashboard

## Project Overview

This project is a Netflix Data Analysis Dashboard created using **Microsoft Power BI**. 
The dashboard provides insights into Netflix movies and TV shows, including content distribution, genres, ratings, countries, and release trends.

## Tool Used

* Microsoft Power BI

## Key Analysis

* Runtime in hours
* Movies vs TV Shows distribution
* Total Movies
* Total TV shows
* Content by year
* Subscribers by county
* Top 5 Genres


## Dashboard

The Power BI dashboard provides interactive visuals and filters to explore Netflix content and identify important trends and patterns.

## Skills Demonstrated

* Data Cleaning
* Data Transformation
* Data Modeling
* Data Visualization
* Power BI
* Interactive Dashboard Development

## Project Outcome

Created an interactive Power BI dashboard to analyze Netflix content and provide meaningful insights into content type, genres, ratings, countries, and release trends.
